# Human and Dog base specimens

The M2 meshes are schematic teaching models. Their surfaces and bilingual descriptions await specialist review.

| Item | Source or review task |
| --- | --- |
| Human testis dimensions | Bilateral length, width and height use the side-specific means in [Lotti et al., Table 2](https://doi.org/10.1111/andr.12951). These describe 248 healthy fertile men. The reference surface is the capsule. The adjacent parenchyma mesh sits slightly inside it. |
| Canine testis dimensions | The bilateral inputs use the ultrasonographic rows of [the canine MPUS pilot, Table 1](https://pmc.ncbi.nlm.nih.gov/articles/PMC11868414/). Its eight dogs were six Beagles and two French Bulldogs. Its confidence intervals describe uncertainty in the mean. |
| Orientation | The human left side is drawn lower. The canine caudal pole is tilted dorsally. The exact tilt, offsets and spacing are illustration choices. Review them with the specimen in lateral view against [Dyce et al., canine pelvis](https://elsevier-elibrary.com/contents/fullcontent/58986/epubcontent_v2/OEBPS/B9781416066071000153.htm). |
| Coverings | A veterinarian and human anatomist should review the open neck, reflections of the tunica vaginalis, insertion of the canine cremaster band and human muscle loops. Thickness and separation are increased to allow selection. See [Gray’s Anatomy](https://elsevier-elibrary.com/contents/fullcontent/58750/epubcontent_v2/OEBPS/B9780443066849500846.htm) and [the UMN carnivore dissection](https://vanat.ahc.umn.edu/carnLabs/Lab15/Lab15.html). |
| Cord and interior | Vessel number and winding, duct trajectories, the illustrative lobules, rete and mediastinum require specialist review. Branch counts are schematic. The proximal cord ends at the upper boundary of the model. The epididymis is displayed continuously from head through tail. |
| Language | Bilingual display names use the project glossary. A native clinical reader should check the full set against the terminology standard before classroom adoption. |
